# Mộng lộ UI art · v1

Generated with the built-in imagegen tool for the owner's requested AFK / preparation experience. These are new Hồn Việt interface assets; no art from the reference game was imported. Text, progress, reward amounts and actions remain live DOM elements.

| Runtime file | Usage | Packaging |
| --- | --- | --- |
| `mong-lo-background-v1.webp` | AFK environment | 1536 px wide, WebP quality 92 |
| `jade-paper-panel-v1.webp` | Reward panel, opponent card and receipt | 1024 px wide, WebP quality 92, alpha 100 |
| `bronze-button-v1.webp` | Challenge, launch and receipt buttons | 768 px wide, WebP quality 92, alpha 100 |

Only uniform resampling and encoding were used for packaging. No color keying, semantic edits or hero assets were generated. The source images remain in the generation history. All game references point to these committed runtime files.
